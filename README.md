# Mathematical_Modeling_Simulation
This git site stores all the computer codes for the Mathematical Modeling and Simulation Class. 
It faciliates the sharing of codes for tutorials, homework assignments, and project. 
Other instructors can help contribute modeling and simulation codes for the course contents, homework exercises, and project problems. Other users can contact the author of this project through email: liuho@erau.edu.
